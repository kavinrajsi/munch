# Shopify Theme Development Resources

## Official Documentation

### Theme Development
https://shopify.dev/docs/themes

Comprehensive guide to building and customizing Shopify themes, including architecture, best practices, and development workflows.

### Liquid Reference
https://shopify.dev/docs/api/liquid

Complete reference for Shopify's Liquid templating language, including filters, tags, and objects.

### Dawn Theme
https://github.com/Shopify/dawn

Shopify's reference theme implementation. Dawn represents current best practices and serves as a foundation for custom theme development.

### Theme Check
https://shopify.dev/docs/themes/tools/theme-check

Linting tool for Shopify themes that helps identify issues and enforce best practices.

## Best Practices

### Performance

- Optimize images (use appropriate sizes)
- Minimize Liquid logic complexity
- Use lazy loading for images
- Defer non-critical JavaScript

### Accessibility

- Use semantic HTML
- Include alt text for images
- Support keyboard navigation
- Ensure sufficient color contrast

### SEO

- Use descriptive page titles
- Include meta descriptions
- Structure content with headings
- Implement schema markup

### Code Quality

- Follow Shopify theme guidelines
- Use consistent naming conventions
- Comment complex logic
- Keep sections focused and reusable
